Consistent or inconsistent?

A system Ax = b is consistent when it has at least one solution. Compare the rank of A with the rank of the augmented matrix [A | b], where n is the number of unknowns.

rank(A) = rank([A | b]) = n

Unique solution. Example: x + y = 3 and x − y = 1 give x = 2, y = 1.

rank(A) = rank([A | b]) < n

Infinitely many solutions. Example: x + y = 2 and 2x + 2y = 4 are the same line, so y can be any value.

rank(A) < rank([A | b])

No solution. Example: x + y = 2 and x + y = 5 reduce to 0 = 3.

After elimination, a row 0 0 0 | c with c ≠ 0 means inconsistent. A row 0 0 0 | 0 carries no information and drops out.
